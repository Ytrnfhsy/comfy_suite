# ComfySuite — генеративний ШІ для PhotoSuite

Генерація зображень через [ComfyUI](https://github.com/comfyanonymous/ComfyUI) прямо в редакторі
[PhotoSuite](https://github.com/eolix/photosuite), за зразком
[Generative AI for Krita](https://github.com/Acly/krita-ai-diffusion): генерація, генеративне
заповнення виділення, доопрацювання, ControlNet, стилі з LoRA, збільшення, живе малювання,
власні графи, черга та історія результатів.

> Код написано з нуля; з krita-ai-diffusion (GPL-3.0) не скопійовано нічого, проєкт розповсюджується
> під MIT.

**Яка у вас версія PhotoSuite?** (Help › About або заголовок стартового екрана)

| Версія | Що встановлювати |
|---|---|
| **0.9.14 – 0.9.15** (Tauri) | **Плагін бічної панелі** — панель «ComfySuite AI» всередині PhotoSuite, у меню **Window**. Див. нижче. |
| **0.9.16 і новіші** (Rust) | Плагінів-панелей там немає → **окреме вікно-компаньйон** ([розділ нижче](#версії-0916-і-новіші-окреме-вікно)). |

## PhotoSuite 0.9.14–0.9.15: панель у бічній панелі

### Встановлення

1. **Покладіть плагін у теку плагінів PhotoSuite.** Простіше за все — склонувати репозиторій
   прямо туди (у корені є `plugin.json`, тож клон і є плагіном):

   ```sh
   # Linux
   cd ~/.local/share/app.photosuite/plugins
   git clone https://github.com/ytrnfhsy/comfy_suite
   # якщо тека comfy_suite там уже є — просто оновіть її:
   cd comfy_suite && git pull
   ```

   | ОС | Тека плагінів |
   |---|---|
   | Linux | `~/.local/share/app.photosuite/plugins/` |
   | macOS | `~/Library/Application Support/app.photosuite/plugins/` |
   | Windows | `%APPDATA%\app.photosuite\plugins\` |

   Або склонуйте куди завгодно і запустіть `sh install-plugin.sh` (Linux/macOS) чи
   `install-plugin.ps1` (Windows) — він скопіює теку `photosuite-plugin/comfy_suite` куди треба.
   Python і `pip install` для панелі **не потрібні**.

2. **Запустіть ComfyUI з дозволом CORS** — панель працює як вебсторінка в пісочниці, і без цього
   браузерний рушій не дасть їй прочитати відповіді ComfyUI:

   ```sh
   python main.py --enable-cors-header
   ```

   (ComfyUI Desktop: Settings › Server-Config › «Enable CORS header», значення `*`.)

   Без значення прапорець дозволяє запити з **будь-якого** сайту, відкритого в браузері на
   машині, яка бачить ComfyUI. Панель плагіна працює в пісочниці з походженням `null`, тож
   достатньо дозволити лише його: `--enable-cors-header null`.

   Якщо ComfyUI на іншому комп'ютері, а порт відкрито лише на `127.0.0.1` сервера, прокиньте його
   SSH-тунелем і лишіть у панелі `http://127.0.0.1:8188`:

   ```sh
   ssh -N -L 8188:127.0.0.1:8188 користувач@сервер
   ```

3. **Перезапустіть PhotoSuite**, відкрийте документ і виберіть **Window › ComfySuite AI**.
   Зелена точка вгорі панелі означає, що ComfyUI підключено. Адреса сервера за замовчуванням —
   `http://127.0.0.1:8188`; інша вказується на вкладці ⚙ або в `config.js`.

### Користування

- **Генерувати** — напишіть запит, натисніть кнопку (або Ctrl+Enter).
  Без виділення генерується все полотно; з виділенням — тільки виділена ділянка з урахуванням
  контексту навколо (результат обрізається маскою виділення); сила < 100 % — **доопрацювання**
  наявного зображення.
- **Режими заповнення** (список ліворуч від кнопки, як у Krita) — діють, коли є виділення:

  | Режим | Що робить |
  |---|---|
  | Авто | Без виділення — усе зображення; з виділенням — «Заповнити», або «Розширити», якщо виділено порожнє полотно |
  | Заповнити | Новий вміст, що зливається з оточенням (ділянка попередньо заповнюється розмиттям довкола) |
  | Розширити | Outpaint: збільште полотно (Image › Canvas Size) і натисніть кнопку — порожня частина знаходиться сама, або виділіть її |
  | Додати об'єкт | Додає описане в запиті (ділянка попередньо нейтрально-сіра) |
  | Видалити об'єкт | Прибирає виділене, заповнюючи його оточенням; порожній запит → «background scenery» |
  | Замінити фон | Виділіть головний об'єкт — замінюється все інше |
  | Власне заповнення | Без попереднього заповнення; свої контекст (авто / межі виділення / усе зображення), розширення й розмиття |

  Сила < 100 % з виділенням — доопрацювання виділеного, незалежно від режиму.

  **Flux 2** працює як модель редагування, так само як у Krita: ділянка є і стартовим латентом
  (перемальовується лише під маскою, з `DifferentialDiffusion`), і референсом; режими додають
  інструкції («Remove the object.», «Expand the image to fill the empty canvas.»…). Для
  **Klein 4B** з установленою outpaint-LoRA (`models/loras/flux-2-klein-4B-outpaint-lora.safetensors`)
  «Заповнити»/«Розширити» фарбують ділянку зеленим і просять «Fill the green spaces according to
  the image.» — без цієї LoRA зелений не використовується (модель його просто скопіювала б).
  Якщо встановлено [comfyui-inpaint-nodes](https://github.com/Acly/comfyui-inpaint-nodes), кольори
  перемальованої ділянки вирівнюються з оточенням (`INPAINT_ColorMatch`).
- Результати з'являються в **Історії**; клік — перегляд, подвійний клік або «Застосувати» —
  додати шаром `[AI] запит (зерно)`. PhotoSuite вставляє його як смарт-об'єкт з активним вільним
  трансформуванням — натисніть **Enter**, щоб підтвердити.
- **+ Додати керування** — ControlNet (scribble, lineart, canny, depth, pose…) з полотна або з файлу;
  `reference` — IP-Adapter.
- **Збільшити** — 1.5–4× моделлю збільшення, з доопрацюванням; відкривається новим документом.
- **Наживо** — перегенерує полотно, поки ви малюєте; «Застосувати» додає поточний варіант шаром.
- **Власний граф** — workflow ComfyUI у форматі API з плейсхолдерами (див. нижче).
- **✎** біля стилю — редактор стилів (чекпойнт, LoRA, семплер, кроки, CFG…).

### Flux 2

Стилі **Flux 2 Dev** і **Flux 2 Klein** будують граф так само, як офіційні шаблони ComfyUI
(Flux.2 Dev / Flux.2 Klein): окремі файли замість чекпойнта, `Flux2Scheduler`,
`SamplerCustomAdvanced`. Файли підбираються автоматично з установлених:

| | Flux 2 Dev | Flux 2 Klein |
|---|---|---|
| `models/diffusion_models` | `flux2_dev_fp8mixed.safetensors` | `flux-2-klein-4b.safetensors` (або 9b, base) |
| `models/text_encoders` | `mistral_3_small_flux2_bf16.safetensors` | `qwen_3_4b.safetensors` (9b → `qwen_3_8b…`) |
| `models/vae` | `flux2-vae.safetensors` | `flux2-vae.safetensors` |

- Конкретні файли можна вибрати в редакторі стилю (поля «Дифузійна модель», «Текстовий енкодер», VAE).
- `cfg` 1 → `BasicGuider` з `FluxGuidance` (Dev, Klein distilled); `cfg` > 1 → `CFGGuider` з
  негативним запитом (Klein base, напр. 20 кроків, cfg 5).
- Заповнення й доопрацювання: латент ділянки з маскою шуму + сама ділянка як референс
  (`ReferenceLatent`), щоб нове узгоджувалося з оточенням (вимикається в стилі).
- Керування для Flux 2 — режим **reference** (рідні референсні зображення Flux 2, кілька можна
  поєднувати); ControlNet для Flux 2 поки не підтримується.
- LoRA для Flux 2 застосовуються лише до моделі (`LoraLoaderModelOnly`), напр. Flux 2 Turbo LoRA
  (тоді ~8 кроків).

### Збереження адреси сервера

Панель працює в пісочниці PhotoSuite і не може сама записувати файли, тому змінене на вкладці ⚙
діє до перезапуску. Щоб адреса ComfyUI зберігалася, один раз виконайте (панель після «Зберегти»
показує цю команду вже з вашою адресою):

```sh
sh ~/.local/share/app.photosuite/plugins/comfy_suite/set-server.sh http://100.64.0.5:8188
```

(macOS: `~/Library/Application Support/app.photosuite/plugins/comfy_suite/set-server.sh`;
Windows: `set-server.ps1` у `%APPDATA%\app.photosuite\plugins\comfy_suite\`.) Адреса
записується в `config.local.js`, який не відстежується git, тож `git pull` її не скидає;
`install-plugin.sh` при перевстановленні теж переносить цей файл (або: `sh install-plugin.sh
http://…:8188`). Інші постійні налаштування (мова, тема, власні стилі — редактор стилів показує
готовий JSON) можна дописати туди ж або в `config.js`.

## Версії 0.9.16 і новіші: окреме вікно

### Як це працює

У PhotoSuite 0.9.16+ немає панелей-плагінів: його WebAssembly-плагіни — це ізольовані фільтри без
доступу до мережі. Зате в нього є **JSON-канал керування** (`photosuite --control <порт>`), через
який можна виконати будь-яку команду редактора. ComfySuite — окреме невелике вікно (PyQt6), яке
тримається поверх PhotoSuite і працює з обома програмами:

```
 PhotoSuite  ◄── JSON по TCP (127.0.0.1, токен) ──►  ComfySuite  ◄── HTTP + WebSocket ──►  ComfyUI
     │                                                    │
     └──── PNG-файли в «папці обміну» (automation root) ──┘
```

- **Знімок полотна**: копія документа (`image.duplicate`, зведена) зберігається в PNG у папці
  обміну. Документ користувача — його шлях, історія, стан збереження — не змінюється.
- **Маска виділення**: у тій самій копії виділення заливається білим на новому шарі над
  прихованим фоном; альфа PNG і є покриттям виділення (з розтушовкою).
- **Керувальний шар**: копія документа, у якій видимим лишається тільки вибраний шар.
- **Результат**: PNG відкривається, копіюється і вставляється в документ новим шаром на потрібне
  місце. Якщо було виділення — через *Paste Into*, тож виділення стає маскою шару, а потім
  відновлюється (`select.reselect`).

ComfySuite використовує лише вбудовані вузли ComfyUI; додаткові пакети вузлів потрібні тільки для
окремих функцій (див. нижче).

### Можливості

| | |
|---|---|
| **Генерація** | Текст → зображення для всього полотна. |
| **Заповнення (inpaint)** | З виділенням: модель бачить виділення разом із контекстом навколо, результат лягає шаром з маскою виділення. |
| **Доопрацювання** | Сила < 100 % — img2img поверх наявних пікселів (усього полотна або виділення). |
| **Автороздільність** | Малі області збільшуються до рідної роздільності моделі (512/1024), великі — зменшуються; результат масштабується назад. |
| **Керувальні шари** | ControlNet: scribble, lineart, softedge, canny, depth, normal, pose, segmentation, blur/tile. Джерело — будь-який шар документа або полотно; сила й діапазон кроків; модель вибирається автоматично за назвою файлу або вручну. |
| **Референс** | IP-Adapter (режим `reference`), якщо встановлено ComfyUI_IPAdapter_plus. |
| **Стилі** | Пресети: чекпойнт (або автовибір), VAE, LoRA, шаблон запиту, негативний запит, семплер, планувальник, кроки, CFG, guidance для Flux, CLIP skip, окремі налаштування для живого режиму. Вбудовано: Cinematic Photo (XL), Digital Artwork (XL), Universal (SD 1.5), Flux, Flux 2 Dev, Flux 2 Klein. |
| **Збільшення** | 1.5×–4× моделлю збільшення (ESRGAN тощо) або Lanczos, з необов'язковим доопрацюванням (тайловий VAE). Результат відкривається новим документом. |
| **Наживо** | Перегенерує полотно (чи виділення) після кожної зміни в документі; результат можна застосувати шаром. |
| **Власний граф** | Будь-який workflow ComfyUI у форматі API з плейсхолдерами `{{prompt}}`, `{{seed}}`, `{{strength}}`… і вузлами `LoadImage` з назвою «PhotoSuite Canvas» / «PhotoSuite Mask». |
| **Черга та історія** | Задачі виконуються по черзі у фоні, їх можна скасувати; результати лишаються в історії з мініатюрами: перегляд, застосування (подвійний клік), «Застосувати все», повтор зерна чи запиту. |
| **Мова** | Українська та англійська (за системною мовою або в налаштуваннях). |

### Вимоги

- PhotoSuite (будь-яка збірка з каналом керування: `--control`).
- ComfyUI — локально або на іншому комп'ютері, з принаймні одним чекпойнтом (SD 1.5, SDXL або Flux у форматі «все в одному»).
- Python 3.10+.
- Необов'язково: [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) для
  препроцесорів (крім Canny, вбудованого в ComfyUI); без нього шар подається в ControlNet як є, тож
  він має вже бути керувальним зображенням (наприклад, ескіз лініями).
  [ComfyUI_IPAdapter_plus](https://github.com/cubiq/ComfyUI_IPAdapter_plus) — для референсних зображень.
  Моделі ControlNet і збільшення — у звичайних папках ComfyUI.

### Встановлення

```sh
git clone https://github.com/ytrnfhsy/comfy_suite
cd comfy_suite
pip install .
```

### Запуск

Найпростіше — дати ComfySuite запустити PhotoSuite з потрібними параметрами:

```sh
comfy-suite launch --photosuite /шлях/до/photosuite  [файл.psd]
```

Це еквівалентно:

```sh
photosuite --control 7878 \
  --control-token-file ~/.config/comfy-suite/photosuite-control.token \
  --automation-read-root  ~/.config/comfy-suite/exchange \
  --automation-write-root ~/.config/comfy-suite/exchange
comfy-suite            # відкрити панель
```

Обидва корені автоматизації мають вказувати на **папку обміну** ComfySuite — інакше PhotoSuite
відмовиться читати й записувати файли. Порт, токен, папку обміну й адресу ComfyUI можна змінити в
налаштуваннях панелі (⚙) або параметрами командного рядка (`--port`, `--token-file`, `--exchange`,
`--comfy`). Налаштування зберігаються в `~/.config/comfy-suite` (Linux),
`~/Library/Application Support/comfy-suite` (macOS), `%APPDATA%\comfy-suite` (Windows).

### Користування

1. Відкрийте або створіть документ у PhotoSuite, у панелі натисніть ⟳ — обидві точки мають стати
   зеленими.
2. Виберіть стиль, напишіть запит і натисніть **Генерувати** (або Ctrl+Enter).
   - Немає виділення, сила 100 % — нове зображення на все полотно.
   - Є виділення — **Заповнити**: генерація лише у виділенні, з урахуванням довкола.
   - Сила менше 100 % — **Доопрацювати** наявне зображення.
3. Результати з'являються в історії. Клік — перегляд, подвійний клік або «✔ Застосувати» —
   додати шаром у документ. Шари мають назви `[AI] запит (зерно)`.
4. «+ Додати керувальний шар» — ControlNet: виберіть режим, шар-джерело і силу.

### Власні workflow

Експортуйте граф у ComfyUI через **Workflow › Export (API)**, у текстових полях напишіть
плейсхолдери, а вузлам `LoadImage` дайте назву `PhotoSuite Canvas` (полотно) або `PhotoSuite Mask`
(виділення). Значення, яке повністю складається з плейсхолдера (`"{{seed}}"`), отримує тип
введеного значення — число лишається числом. `{{canvas}}`, `{{mask}}`, `{{width}}`, `{{height}}`
заповнюються автоматично, для решти панель створює поля. Приклад —
[`workflows/img2img-example.json`](workflows/img2img-example.json).

### Командний рядок

```sh
comfy-suite info                                  # перевірити з'єднання та моделі
comfy-suite generate "a lighthouse at dusk" --batch 2 --apply 0
comfy-suite generate "add a hat" --strength 0.6   # доопрацювати / заповнити виділення
comfy-suite upscale --factor 2 --model 4x-UltraSharp.pth --refine 0.3
```

### Обмеження

- PhotoSuite не дає вбудовувати панелі, тож ComfySuite — окреме вікно (за замовчуванням поверх
  інших).
- Регіони (окремі запити для частин зображення, як у Krita) і анімація поки не реалізовані.
- Історія живе протягом сесії панелі.
- Вставка результату тимчасово відкриває й закриває документ у PhotoSuite, а в історії документа
  з'являються кроки «Paste»/«Reselect».
- Під час експорту PhotoSuite показує сповіщення «Saved … with 1 warning (layers flattened)» —
  це про тимчасову зведену копію, документ користувача не зачіпається.

## Розробка

```sh
pip install -e ".[dev]"
pytest -q
```

Тести з фіктивним сервером ComfyUI виконуються завжди; JS-логіка плагіна — через `node --test
tests/plugin/unit.test.mjs` (pytest запускає її сам, якщо є node). Наскрізні тести плагіна
запускають справжній інтерфейс PhotoSuite 0.9.15 у Chromium (Playwright): вкажіть у
`PHOTOSUITE_WEB` теку `src` з checkout-а PhotoSuite 0.9.15 після `scripts/submodules-setup.sh`. Інтеграційні тести зі справжнім рушієм
PhotoSuite запускаються, якщо доступний `photosuite-cli` (зберіть
`cargo build --release -p photosuite-cli` у репозиторії PhotoSuite і вкажіть шлях у
`PHOTOSUITE_CLI`).
