# ComfySuite — генеративний ШІ для PhotoSuite

Панель-компаньйон, що додає до редактора [PhotoSuite](https://github.com/eolix/photosuite)
генерацію зображень через [ComfyUI](https://github.com/comfyanonymous/ComfyUI). Задумана за
зразком [Generative AI for Krita](https://github.com/Acly/krita-ai-diffusion): генерація,
генеративне заповнення виділення, доопрацювання, ControlNet, збільшення, живе малювання,
черга задач та історія результатів.

> Код написано з нуля; з krita-ai-diffusion (GPL-3.0) не скопійовано нічого, проєкт розповсюджується
> під MIT.

## Як це працює

PhotoSuite не підтримує панелей-плагінів: його WebAssembly-плагіни — це ізольовані фільтри без
доступу до мережі. Зате в нього є **JSON-канал керування** (`photosuite --control <порт>`), через
який можна виконати будь-яку команду редактора. ComfySuite — окреме невелике вікно (PyQt6), яке
тримається поверх PhotoSuite і працює з обома програмами:

```
 PhotoSuite  ◄── JSON по TCP (127.0.0.1, токен) ──►  ComfySuite  ◄── HTTP + WebSocket ──►  ComfyUI
     │                                                    │
     └──── PNG-файли в «папці обміну» (automation root) ──┘
```

- **Знімок полотна**: копія документа (`image.duplicate`, зведена) зберігається в PNG у папці
  обміну. Документ користувача — його шлях, історія, стан збереження — не змінюється.
- **Маска виділення**: у тій самій копії виділення заливається білим на новому шарі над
  прихованим фоном; альфа PNG і є покриттям виділення (з розтушовкою).
- **Керувальний шар**: копія документа, у якій видимим лишається тільки вибраний шар.
- **Результат**: PNG відкривається, копіюється і вставляється в документ новим шаром на потрібне
  місце. Якщо було виділення — через *Paste Into*, тож виділення стає маскою шару, а потім
  відновлюється (`select.reselect`).

ComfySuite використовує лише вбудовані вузли ComfyUI; додаткові пакети вузлів потрібні тільки для
окремих функцій (див. нижче).

## Можливості

| | |
|---|---|
| **Генерація** | Текст → зображення для всього полотна. |
| **Заповнення (inpaint)** | З виділенням: модель бачить виділення разом із контекстом навколо, результат лягає шаром з маскою виділення. |
| **Доопрацювання** | Сила < 100 % — img2img поверх наявних пікселів (усього полотна або виділення). |
| **Автороздільність** | Малі області збільшуються до рідної роздільності моделі (512/1024), великі — зменшуються; результат масштабується назад. |
| **Керувальні шари** | ControlNet: scribble, lineart, softedge, canny, depth, normal, pose, segmentation, blur/tile. Джерело — будь-який шар документа або полотно; сила й діапазон кроків; модель вибирається автоматично за назвою файлу або вручну. |
| **Референс** | IP-Adapter (режим `reference`), якщо встановлено ComfyUI_IPAdapter_plus. |
| **Стилі** | Пресети: чекпойнт (або автовибір), VAE, LoRA, шаблон запиту, негативний запит, семплер, планувальник, кроки, CFG, guidance для Flux, CLIP skip, окремі налаштування для живого режиму. Вбудовано: Cinematic Photo (XL), Digital Artwork (XL), Universal (SD 1.5), Flux. |
| **Збільшення** | 1.5×–4× моделлю збільшення (ESRGAN тощо) або Lanczos, з необов'язковим доопрацюванням (тайловий VAE). Результат відкривається новим документом. |
| **Наживо** | Перегенерує полотно (чи виділення) після кожної зміни в документі; результат можна застосувати шаром. |
| **Власний граф** | Будь-який workflow ComfyUI у форматі API з плейсхолдерами `{{prompt}}`, `{{seed}}`, `{{strength}}`… і вузлами `LoadImage` з назвою «PhotoSuite Canvas» / «PhotoSuite Mask». |
| **Черга та історія** | Задачі виконуються по черзі у фоні, їх можна скасувати; результати лишаються в історії з мініатюрами: перегляд, застосування (подвійний клік), «Застосувати все», повтор зерна чи запиту. |
| **Мова** | Українська та англійська (за системною мовою або в налаштуваннях). |

## Вимоги

- PhotoSuite (будь-яка збірка з каналом керування: `--control`).
- ComfyUI — локально або на іншому комп'ютері, з принаймні одним чекпойнтом (SD 1.5, SDXL або Flux у форматі «все в одному»).
- Python 3.10+.
- Необов'язково: [comfyui_controlnet_aux](https://github.com/Fannovel16/comfyui_controlnet_aux) для
  препроцесорів (крім Canny, вбудованого в ComfyUI); без нього шар подається в ControlNet як є, тож
  він має вже бути керувальним зображенням (наприклад, ескіз лініями).
  [ComfyUI_IPAdapter_plus](https://github.com/cubiq/ComfyUI_IPAdapter_plus) — для референсних зображень.
  Моделі ControlNet і збільшення — у звичайних папках ComfyUI.

## Встановлення

```sh
git clone https://github.com/ytrnfhsy/comfy_suite
cd comfy_suite
pip install .
```

## Запуск

Найпростіше — дати ComfySuite запустити PhotoSuite з потрібними параметрами:

```sh
comfy-suite launch --photosuite /шлях/до/photosuite  [файл.psd]
```

Це еквівалентно:

```sh
photosuite --control 7878 \
  --control-token-file ~/.config/comfy-suite/photosuite-control.token \
  --automation-read-root  ~/.config/comfy-suite/exchange \
  --automation-write-root ~/.config/comfy-suite/exchange
comfy-suite            # відкрити панель
```

Обидва корені автоматизації мають вказувати на **папку обміну** ComfySuite — інакше PhotoSuite
відмовиться читати й записувати файли. Порт, токен, папку обміну й адресу ComfyUI можна змінити в
налаштуваннях панелі (⚙) або параметрами командного рядка (`--port`, `--token-file`, `--exchange`,
`--comfy`). Налаштування зберігаються в `~/.config/comfy-suite` (Linux),
`~/Library/Application Support/comfy-suite` (macOS), `%APPDATA%\comfy-suite` (Windows).

## Користування

1. Відкрийте або створіть документ у PhotoSuite, у панелі натисніть ⟳ — обидві точки мають стати
   зеленими.
2. Виберіть стиль, напишіть запит і натисніть **Генерувати** (або Ctrl+Enter).
   - Немає виділення, сила 100 % — нове зображення на все полотно.
   - Є виділення — **Заповнити**: генерація лише у виділенні, з урахуванням довкола.
   - Сила менше 100 % — **Доопрацювати** наявне зображення.
3. Результати з'являються в історії. Клік — перегляд, подвійний клік або «✔ Застосувати» —
   додати шаром у документ. Шари мають назви `[AI] запит (зерно)`.
4. «+ Додати керувальний шар» — ControlNet: виберіть режим, шар-джерело і силу.

### Власні workflow

Експортуйте граф у ComfyUI через **Workflow › Export (API)**, у текстових полях напишіть
плейсхолдери, а вузлам `LoadImage` дайте назву `PhotoSuite Canvas` (полотно) або `PhotoSuite Mask`
(виділення). Значення, яке повністю складається з плейсхолдера (`"{{seed}}"`), отримує тип
введеного значення — число лишається числом. `{{canvas}}`, `{{mask}}`, `{{width}}`, `{{height}}`
заповнюються автоматично, для решти панель створює поля. Приклад —
[`workflows/img2img-example.json`](workflows/img2img-example.json).

### Командний рядок

```sh
comfy-suite info                                  # перевірити з'єднання та моделі
comfy-suite generate "a lighthouse at dusk" --batch 2 --apply 0
comfy-suite generate "add a hat" --strength 0.6   # доопрацювати / заповнити виділення
comfy-suite upscale --factor 2 --model 4x-UltraSharp.pth --refine 0.3
```

## Обмеження

- PhotoSuite не дає вбудовувати панелі, тож ComfySuite — окреме вікно (за замовчуванням поверх
  інших).
- Регіони (окремі запити для частин зображення, як у Krita) і анімація поки не реалізовані.
- Історія живе протягом сесії панелі.
- Вставка результату тимчасово відкриває й закриває документ у PhotoSuite, а в історії документа
  з'являються кроки «Paste»/«Reselect».

## Розробка

```sh
pip install -e ".[dev]"
pytest -q
```

Тести з фіктивним сервером ComfyUI виконуються завжди. Інтеграційні тести зі справжнім рушієм
PhotoSuite запускаються, якщо доступний `photosuite-cli` (зберіть
`cargo build --release -p photosuite-cli` у репозиторії PhotoSuite і вкажіть шлях у
`PHOTOSUITE_CLI`).

| Модуль | Призначення |
|---|---|
| `comfy_suite/photosuite.py` | Клієнт каналу керування та обмін зображеннями з документом |
| `comfy_suite/comfy.py` | Клієнт ComfyUI: моделі, завантаження, черга, прогрес, результати |
| `comfy_suite/workflow.py` | Побудова графів ComfyUI (txt2img, img2img, inpaint, ControlNet, IP-Adapter, upscale, custom) |
| `comfy_suite/generator.py` | Сценарії: прочитати документ → згенерувати → повернути результат |
| `comfy_suite/jobs.py` | Черга задач та історія |
| `comfy_suite/styles.py` | Стилі-пресети |
| `comfy_suite/ui/` | Інтерфейс (PyQt6) |
